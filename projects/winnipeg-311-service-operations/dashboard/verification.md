# Native Tableau verification — 1 November 2026

Delegated technical check in Tableau Desktop Free Edition 2026.2 (macOS, computer
use), in presentation mode, against the committed `../results` CSVs. This is a
technical check by the author's tooling, not stakeholder acceptance.

The workbook is generated by [`scripts/build_tableau.py`](../scripts/build_tableau.py);
structural tests are in [`tests/test_service_tableau.py`](../tests/test_service_tableau.py).
Expected values were computed independently with SQL over the same CSVs.

## Defects found and fixed during the check

1. The second subtitle line was cut off; the subtitle zone was enlarged.
2. Median days showed two decimals and dropped trailing zeros (`17`, `1`); the
   cell and column formats now use Tableau's numeric code (`n#,##0.0`).
3. A custom month-axis format had no effect and was removed; axes keep Tableau's
   default date labels.

The corrected file reopened without load warnings, and the screenshots below
come from it.
